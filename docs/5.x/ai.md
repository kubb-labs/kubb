# AI assistants

An AI assistant can run Kubb through the CLI or the built-in MCP server, and read the Kubb docs to write a correct config.

| Tool | What it does | Guide |
| --- | --- | --- |
| Claude Code | Slash commands, an agent, and skills that run the `kubb` CLI | [Set up the Claude Code plugin](/docs/5.x/ai/claude) |
| Claude Desktop, Cursor, VS Code | Run `generate`, `validate`, and `init` over MCP | [Set up the MCP server](/docs/5.x/ai/mcp) |
| Context7 | Current Kubb docs inside any assistant with Context7 | [Give an assistant the Kubb docs](/docs/5.x/ai/docs#context7) |
| Any assistant that reads URLs | `llms.txt` and `llms-full.txt` feeds | [Give an assistant the Kubb docs](/docs/5.x/ai/docs#llms-txt) |
| Claude Desktop with your API | Call your API through a server generated by `@kubb/plugin-mcp` | [Connect it to Claude Desktop](/extensions/kubb-labs/plugin-mcp/guides/server#claude-desktop) |
