# AI assistants

Kubb works with AI assistants in two directions. An assistant can run Kubb through the CLI or the built-in MCP server, and it can read the Kubb documentation to write a correct configuration.

## Supported tools

| Tool | What it does | Guide |
| --- | --- | --- |
| Claude Code | Slash commands, an agent, and skills that run the `kubb` CLI | [Set up the Claude Code plugin](/docs/5.x/ai/claude) |
| Claude Desktop, Cursor, VS Code | Run `kubb generate`, `validate`, and `init` over MCP | [Set up the MCP server](/docs/5.x/ai/mcp) |
| Context7 | Current Kubb docs inside any assistant with Context7 | [Use Kubb with Context7](/docs/5.x/ai/context7) |
| Any assistant that reads URLs | `llms.txt` and `llms-full.txt` feeds | [Use documentation in an AI assistant](/docs/5.x/ai/llmstxt) |
| Claude Desktop with your API | Call your API through a server generated by `@kubb/plugin-mcp` | [Connect an API server to Claude Desktop](/docs/5.x/ai/claude-desktop) |
