Publish JSON Schemas for the Kubb boundaries: `@kubb/ast/schemas/ast.json` for the AST, `@kubb/ast/schemas/file.json` for `FileNode`, `@kubb/core/schemas/diagnostic.json` for diagnostics and `@kubb/core/schemas/config.json` for the data part of the config, plugins included. Tools in other languages can read and check Kubb data with them.
